To run this application please ensure you locally mpve this reposirty and run the A3.java file by using an IDE (Integrated Development Environment) such as Eclipse (IDE for Java Developers version) and install the Java Development Kit (JDK).

## To run this project (must be done locally), do the following:


### Clone or Download the Repository
- Download the ZIP file or clone the repository to your local machine.
- Install Java Development Kit (JDK). Make sure the JDK is installed on your system. Download it from the official website: https://www.oracle.com/java/technologies/downloads/
- Install Eclipse IDE (for Java Developers) Download Eclipse IDE for Java Developers: https://www.eclipse.org/downloads/packages/


### Open the Project in Eclipse
- Launch Eclipse.
- Select File → Open Projects from File System (or Import → Existing Projects into Workspace).
- Locate and import the project folder.
- Run the Application
- Open the A3.java file.
- Right-click the file.
- Select Run As → Java Application.

The application window should open, displaying the bouncing shapes.
